# JH AI Creator (Phase 2 স্টার্টার)

নতুন Next.js 14 + TypeScript প্রজেক্ট। ডেমো HTML-এর এডিটর এখানে কম্পোনেন্ট হিসেবে আছে।

## চালু করার নিয়ম
```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # টাইপ যাচাই
```
Node 18.18+ দরকার। Phase 2-তে কোনো `.env` লাগে না।

## এখন যা কাজ করে (লক্ষ্য, এখনো পুরো টেস্ট হয়নি)
- ভিডিও আপলোড (ব্রাউজারে থাকে), প্রিভিউ, প্লে, একাধিক ক্লিপ
- প্লেহেডে স্প্লিট, ডিলিট (গ্যাপ বন্ধ), ব্রাইটনেস/কনট্রাস্ট/স্যাচুরেশন/জুম
- Undo/Redo (১০০ ধাপ), অটোসেভ (প্রজেক্ট JSON, localStorage)
- মালিকানা ঘোষণা + কপিরাইট রিভিউ (GREEN/YELLOW/RED), বাংলা/English

## এখনো নেই (ভুয়া বাটন নেই, নেইগুলো disabled)
- আসল MP4 এক্সপোর্ট (Phase 3, FFmpeg)
- AI জেনারেশন/ভয়েস (Phase 4), ছবি আপলোড, ক্রপ/রোটেট, ট্রানজিশন, অডিও ট্র্যাক, টেক্সট/সাবটাইটেল, মাল্টি-ট্র্যাক
- লগইন, Supabase সংযোগ, Free/Paid প্ল্যান, অ্যাডমিন (Phase 5–6)
- রিলোডের পর ভিডিও ফাইল আবার আপলোড করতে হয়

## ফোল্ডার
- `src/features/editor/` মডেল, Undo/Redo, টাইমলাইন, এডিটর UI
- `src/lib/copyright/review.ts` রিস্ক নিয়ম (ফিল্টার/স্পিড/ক্রপে ফল বদলায় না)
- `src/lib/ai/provider.ts` AI প্রোভাইডার ইন্টারফেস (সার্ভার-অনলি)
- `src/lib/plans/config.ts` Free ডিফল্ট সীমা
- `supabase/migrations/0001_phase2_projects.sql` **এখনো চালানো হয়নি**, আগে রিভিউ করুন

## নিরাপত্তা
`.env.example` শুধু খালি ফর্ম। আসল কী কখনো কমিট বা ফ্রন্টএন্ডে রাখবেন না। `SUPABASE_SERVICE_ROLE_KEY` শুধু সার্ভারে।

## কপিরাইট নোট
রিভিউ একটি অভ্যন্তরীণ ঝুঁকি মূল্যায়ন, আইনি নিশ্চয়তা নয়। কোনো ভিডিও ক্লেইম-মুক্ত হবে তার প্রতিশ্রুতি নেই।
